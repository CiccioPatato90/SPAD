# SPAD

Small Python simulation of SPAD (single-photon avalanche diode) time-of-flight
measurements and inertial sensor fusion. The project models photon detections,
background-light effects and range noise, then uses simulated measurements to
estimate depth along an underwater trajectory.

## Run

The project requires Python 3.12 or newer and uses `uv` for dependency
management.

```bash
uv sync
uv run main.py
```

This runs the sensor-fusion simulation and writes `low.png`.

To run the SPAD model compliance checks:

```bash
uv run spad_model.py
```

This produces `compliance_tests.png` and reports the test results in the
terminal.

## Files

- `main.py`: underwater trajectory simulation and Kalman filter fusion of SPAD
  and accelerometer readings.
- `spad_model.py`: physics-based SPAD LiDAR measurement model and compliance
  checks.
- `*.png`: plots generated by simulations and experiments.
